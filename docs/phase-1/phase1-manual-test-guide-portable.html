Text limits are counted in characters

Do this

Copyable commands · R07
python3 - <<'PYTHON'
import urllib.request, urllib.parse, urllib.error
class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, *args): return None
opener = urllib.request.build_opener(NoRedirect)
for label, expected, changes in [
    ('short-255',303,{'strapline':'é'*255}),
    ('short-256',422,{'strapline':'é'*256}),
    ('title-201',422,{'title':'T'*201}),
    ('body-100001',422,{'body':'L'*100001}),
]:
    values = {'title':label,'path':'limits-'+label,'body':'valid','strapline':''}
    values.update(changes)
    req = urllib.request.Request('http://127.0.0.1:8081/admin/pages', data=urllib.parse.urlencode(values).encode())
    try: response = opener.open(req)
    except urllib.error.HTTPError as e: response = e
    text = response.read().decode()
    print(label, 'HTTP', response.code, 'expected', expected)
    assert response.code == expected
    if expected == 422: assert 'data-error-code="too_long"' in text
PYTHON

S04

Older/newer schema and configuration versions never serve

Do this

  1. Keep B stopped while making fresh standalone backup copies. The script below creates six copies: schema marker, site config marker and document format version, each at 0 and 2.
  2. For each, it starts a subprocess with an unused random loopback port and a five-second deadline, captures exit/diagnostics and checks committed rows/schema did not change.
  3. Restart original B afterward.
Copyable commands · S04
python3 - "$PHASE1_LAB" <<'PYTHON'
import json, sqlite3, subprocess, sys
from pathlib import Path
root=Path(sys.argv[1])
def state(db):
    return (list(db.iterdump()),db.execute('PRAGMA application_id').fetchone(),db.execute('PRAGMA user_version').fetchone(),db.execute('PRAGMA journal_mode').fetchone())
for kind in ('schema','site-config','document-config'):
    for version in (0,2):
        folder=root/f'{kind}-{version}'; folder.mkdir()
        source=sqlite3.connect((root/'b'/'composure.db').as_uri()+'?mode=rw',uri=True)
        db=sqlite3.connect(folder/'composure.db'); source.execute('PRAGMA query_only=ON'); source.backup(db); source.close()
        db.execute('PRAGMA journal_mode=WAL')
        if kind=='schema': db.execute(f'PRAGMA user_version={version}')
        elif kind=='site-config': db.execute('UPDATE site SET config_format_version=?',(version,))
        else:
            doc=json.loads(db.execute('SELECT document FROM active_config').fetchone()[0])
            doc['format_version']=version
            db.execute('UPDATE active_config SET document=?',(json.dumps(doc),))
        db.commit(); before=state(db); db.close()
        result=subprocess.run([str(root/'composure'),'serve','--site',str(folder),'--addr','127.0.0.1:0'],capture_output=True,text=True,timeout=5)
        print(folder.name,'exit',result.returncode,result.stderr.strip())
        assert result.returncode==4 and not result.stdout
        assert ('older' if version==0 else 'newer') in result.stderr
        db=sqlite3.connect((folder/'composure.db').as_uri()+'?mode=rw',uri=True)
        db.execute('PRAGMA query_only=ON')
        assert state(db)==before; db.close()
print('PASS: six unsupported version boundaries preserve state')
PYTHON

Expected result

  • All six exit 4, no listening line, one prefixed diagnostic distinguishing older/newer version. No migration/import/content mutation.
  • A timeout is a failure: it would mean an incompatible site began serving instead of refusing startup. Original B remains supported and starts normally.
