## Contract findings

| Boundary | Inspected decision and evidence |
| --- | --- |
| Version markers | `format_version: 1` identifies the file format; `site.config_format_version: 1` records the active document format; SQLite `PRAGMA user_version: 1` identifies the schema; and `active_config.revision` identifies the site's active revision. The configuration file contains only its format version and definitions. New-site init starts the active revision at 1. |
| IDs and order | The file contains exactly one `page` type. Field IDs use the lowercase ASCII grammar, with `title` and `path` reserved. The custom example keeps `body` and adds `strapline`; the form order is `strapline` then `body`. Export and init preserve definition IDs and settings. Export sorts content types by ID and fields by numeric order then ID. |
| Closed validation | Unknown properties, unknown kinds, additional types, invalid/reserved/duplicate IDs, duplicate field order, missing or wrong-typed values, and duplicate decoded JSON member names are rejected. Version integers other than 1 exit 4; other invalid inputs exit 3. The validator's first-error and path rules are explicit. |
| Values and seed | `short_text` is limited to 255 decoded Unicode code points, without normalization or truncation. Existing `long_text` body rules remain in the content contract. The fixed example seed is checked against the chosen definition before filesystem/database writes; an incompatible required field rejects the entire initialization. The ordinary second-site journey omits `--example`. |
| Validation, export, init, restart | `config validate` reads one file without opening a site or writing files. Export reads `active_config.document`, writes only the requested definition file, and does not mutate site state. Canonical output has fixed property and array ordering, UTF-8, two-space indentation, and one final LF. It installs a complete temporary file by rename, replaces an existing output on success, and preserves the old output on failure. Init validates before writes; without `--apply` it changes nothing. Ordinary restart checks stored versions and never imports an edited file. |
| Excluded data | Configuration contains definitions and settings only. It excludes Page values, snapshots, site IDs, active revisions, accounts, audit records, credentials, deployment secrets, media, and recovery manifests. The separate `seed-page.json` is example content for init, not a configuration file or export. |
| Deployment and model changes | Production configuration remains deploy-only under the ADR. A future deploy command must check its expected active revision/hash again before apply and reject drift. Required-field changes or tighter validation need a preflight; destructive type/field changes are rejected under the stated v1 rules. Runtime DDL, implicit coercion, and configuration deployment are outside phase 1. |
| References and audit | Phase 1 has no relationship, cross-record, or file-reference property, so #3's invalid-reference fixture criterion is inapplicable. Full reference integrity is phase 6/#21. Audit-envelope design remains phase 2/#22. Neither blocks this contract. |

import json
from pathlib import Path

class Pairs:
    def __init__(self, pairs): self.pairs = pairs

def walk(value, path, found):
    if isinstance(value, Pairs):
        seen = set()
        for key, child in value.pairs:
            keypath = f"{path}.{key}" if key.isidentifier() else f"{path}[{json.dumps(key, ensure_ascii=False)}]"
            if key in seen: found.append(keypath)
            seen.add(key)
            walk(child, keypath, found)
    elif isinstance(value, list):
        for i, child in enumerate(value): walk(child, f"{path}[{i}]", found)

files = sorted(Path('docs/phase1/examples').glob('*.json')) + sorted(Path('docs/phase1/examples/config-invalid').glob('*.json'))
all_dupes = []
for file in files:

    dupes = []
    walk(parsed, '$', dupes)
    print(f"PARSED {file}")
    all_dupes.extend((str(file), path) for path in dupes)
print(f"TOTAL {len(files)} JSON files parsed")
print(f"DUPLICATE MEMBERS {all_dupes}")
PY
