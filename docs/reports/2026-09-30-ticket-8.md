# Ticket 8: Preview saved Page drafts with the public renderer

Issue: [#8](https://github.com/markdlabrecque/composure/issues/8)

## Delivered

Added a GET/HEAD admin preview for the latest persisted Page draft using the shared public renderer. The preview context sits outside the shared content region, and saved edit forms link to the preview with save-before-preview guidance. Preview responses are private and non-indexable; requests do not mutate persisted state. The admin flow documentation records the renderer parity contract for tickets 9 and 10.
